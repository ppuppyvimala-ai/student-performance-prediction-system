EduPredict – Student Performance Prediction and Analysis System

Project Overview

EduPredict is a web-based application designed to monitor, analyze, and predict student academic performance. It helps students and administrators understand academic progress through student records, attendance tracking, and performance analytics.

Main Features

- Student Login and Dashboard
- Admin Portal
- Faculty Directory
- Student Performance Analytics
- Subject-wise Attendance Tracking
- What-If Analysis Lab
- Academic Performance Prediction
- Responsive User Interface

Technologies Used

- React
- TypeScript
- HTML
- CSS
- Tailwind CSS
- JavaScript
- Node.js
- Express.js
- Chart.js

Project Objective

To provide a centralized platform for tracking student academic progress and identifying areas where students may need improvement.
